# P(-1) Audit — 1.5.3 sweep

> **Auditor**: Claude Code, plus three independent subagent reviews (security
> and input hardening; correctness and determinism; external spec and practice
> research) · **Date**: 2026-11-12 · **Baseline**: 1.5.2 (cyrius 6.7.18),
> 314/0, every gate clean. · **Status**: **complete.** Every planned repair
> and decision landed in 1.5.3: 493/0, 5 fuzz harnesses passing under
> `--poison=ab`, every gate clean. See Final status.

## Method

- **Baseline:** tests, fuzz, the five CLAUDE.md gates, and a labelled bench run
  (`1.5.3-baseline` in `bench-history.csv`).
- **Reviews:** two code reviews by independent readers, each given the code and
  the questions but no hypotheses. Findings were **proven by running probe
  programs** wherever possible. Probes live in the session scratchpad;
  regression tests in `tests/nous.tcyr`.
- **Research:** checked behaviour against the specs: SemVer 2.0.0, npm and Cargo
  ranges, deb-version(7), Debian Policy §5.6 / §7, apt(8), apt-cache(8),
  dpkg-query(1). Also compared resolver practice in PubGrub, Cargo, uv, apt
  solver3 and TUF.
- **Own review:** read all of `src/`, did a namespace audit against the 6.7.18
  stdlib and every sibling repo, and ran scale benchmarks at realistic sizes.
- **Verification:** every finding acted on was re-verified here. apt findings
  were checked on Debian 12 in docker. Fixes are pinned by tests that fail on
  the old code.

The chosen version is never checked (`>=2.0.0` resolved to 1.0.0). `constraints_compatible` samples ~5 versions, so `>1.2.0` with `<1.3.0` "conflicts" and swapping the arguments changes the answer | Intersect every constraint as a version range and check the chosen version. ### Re-assessed seeds

- **Retire `our_is_dir` → no.** The stdlib `is_dir` does open + getdents +
  close (3 syscalls) where nous does one `stat`, and `dir_size_recursive` calls
  it on every entry. The real smell was three copies of the stat buffer,
  handled with the stat helpers.

### Moved to the roadmap (capabilities, not repairs)

- **Version selection and backtracking.** A PubGrub-style solver, preferring
  locked versions, with major versions able to coexist and causal-chain
  explanations. Without it nous rejects sets solvable by an older version
  (research #18). Target: 1.7.x with the lockfile, and the 1.8.x native index.
- **Lockfile integrity.** Hash every node, transitive ones included; refuse
  unlocked nodes in locked mode (pip / Cargo practice). Target: 1.7.x.
- **Rollback and freeze protection.** Track the highest version seen; signed,
  expiring metadata (TUF §1.5.2). Target: 1.8.x / 1.9.x.
- **The system leg via apt's own solver.** `apt-get -s` instead of re-deriving
  Depends (research #13, #16: `apt list` is not a script interface, and admin
  `APT::Cmd::format` changes its output).
- **Portability.** The `struct stat` offsets in `src/util.cyr` are x86_64-only;
  aarch64's layout differs.
